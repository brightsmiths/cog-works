Implement `LlmGateway::call`, `assemble_constitutional_prompt`, and `BudgetTracker` in `crates/nodes`, completing the LLM gateway and cost-budget subsystems that every pipeline node will call through.

- **`LlmGateway::call`** now fully implements the documented contract (`docs/spec/interfaces/nodes.md` §LlmGateway::call): it performs a pre-flight rate-limit backoff check, assembles the constitutional + node system prompt, converts the context package into provider chat messages, delegates to the injected `LlmProvider`, and records post-call rate-limit state. The shared rate-limit mutex is held only for the pre-flight check and the post-call bookkeeping — it is never held across the provider's HTTP call, so concurrent nodes sharing one gateway can make requests in parallel even while one of them is waiting on a response.
- **`assemble_constitutional_prompt`** now validates constitutional rules (approved source branch, hash integrity, required rule signatures) before wrapping them into the opaque `ConstitutionallyWrappedPrompt` token. Its signature changed from `-> ConstitutionallyWrappedPrompt` to `-> Result<ConstitutionallyWrappedPrompt, ConstitutionalError>` so validation failures can be propagated instead of silently producing an unwrapped token. There are no external consumers of this pre-1.0 crate yet, but any future internal caller (pipeline executor, node implementations landing in follow-up PRs) must handle the `Result`.
- **`BudgetTracker::new`/`try_acquire`** now atomically enforce the cost-budget ceiling: the internal mutex is held for the full check-and-update sequence, so concurrent nodes sharing one `BudgetTracker` clone cannot race past the budget limit between the check and the accumulator update.

No public API shapes changed other than the `assemble_constitutional_prompt` return type noted above — all other types (`LlmGateway`, `BudgetTracker`, `RateLimitState`, `ConstitutionallyWrappedPrompt`) were already fully specified; this change fills in their previously-`todo!()` implementation bodies. No breaking change in practice: nothing could successfully call these functions before (they always panicked via `todo!()`), and no other crate in the workspace calls them yet — the `cli` crate and the remaining node implementations (`#18`, `#22`) that will use this gateway and tracker land in follow-up PRs.
